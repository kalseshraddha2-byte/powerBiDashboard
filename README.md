# powerBiDashboard
# 📊 Financial Growth Analysis Dashboard (2023–2025)

## 1. Project Title / Headline

**Financial Growth Analysis: Sales and Profit Insights Dashboard**

An interactive Power BI dashboard designed to analyze financial growth, sales performance, net profit, and regional business performance from 2023 to 2025.

## 2. Short Description / Purpose

The Financial Growth Dashboard is an interactive data visualization report developed using Microsoft Power BI. It helps users understand year-wise sales growth, profit trends, regional sales distribution, and product category performance to support data-driven business decisions.

## 3. Tech Stack

The dashboard was developed using the following tools and technologies:

- 📊 Microsoft Power BI Desktop – Dashboard creation and data visualization.
- 🔄 Power Query – Data cleaning and transformation.
- 🧮 DAX – Calculations and financial measures.
- 📁 Excel / CSV – Data source, if applicable.
- 📈 Data Visualization – Charts, graphs, and KPI analysis.

## 4. Key Features

- Financial growth analysis for 2023–2025.
- Sales Growth Percentage analysis.
- Profit Growth Percentage analysis.
- Year-wise Net Profit visualization.
- Regional Sales Analysis.
- Sales analysis by product category.
- Interactive charts and visual reports.

## 5. Dashboard Components

The dashboard includes the following visualizations:

- Profit Growth KPI
- Sales Growth KPI
- Net Profit by Year
- Sales by Region
- Sales by Product Category
- Year-wise Financial Performance

## 6. Business Objectives

- Monitor financial performance across multiple years.
- Identify sales and profit growth trends.
- Compare sales performance across regions.
- Understand product category contributions.
- Support better business planning and decision-making.

## 7. Key Insights

The dashboard allows users to explore financial performance, compare regional sales, identify leading product categories, and understand changes in sales and profit over time.
